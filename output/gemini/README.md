# 학생용 양산 정책 탐구 질문친구

학생의 물음에서 출발해 한 번에 하나의 질문을 건네고, 학생의 답에 따라 다음 질문을 고르는 소크라테스식 문답 자료입니다. 고정 점검표를 차례로 묻거나 학생의 글을 대신 작성하지 않습니다.

## 학교 계정에서 Gem 구성하기

1. 이름: **양산 정책 탐구 질문친구**
2. 설명: `Gem_학생안내.txt`의 내용을 넣습니다.
3. 요청 사항: `Gem_요청사항.txt`의 내용을 넣습니다. 이름·설명은 이 칸에 중복해서 넣지 않습니다.
4. 기본 도구: 없음.
5. 지식: `학생용_Gem_지식자료` 폴더의 파일 7개를 추가합니다. ZIP을 받았다면 압축을 푼 뒤 파일을 선택합니다.
6. 지식 출처 사용 중지는 선택하지 않습니다.
7. 미리보기에서 학생의 질문에 응답한 뒤 질문 하나만 하고 기다리는지 확인하고 저장합니다.

학생에게 배포할 때는 공유 권한을 뷰어로 설정하고 실제 학생 계정에서 접속을 확인합니다. 조직의 Gemini·공유 설정에 따라 사용 가능 여부가 다릅니다. 2026-10-15 확인 당시 스킬은 성인 개인 계정 중심으로 제공되어 학생 배포용 Gem과 구분했습니다.

`SKILL.md`와 `yangsan-question-coach.zip`은 스킬 업로드용 별도 산출물입니다. `Gem_설정문.txt`는 이름·설명·요청 사항을 함께 담은 초기 참고본이며, 실제 입력은 위의 분리된 파일을 사용합니다.

## 지식 자료

- 2026 인구정책 가이드북·로드맵, 2025 시행계획 원문 PDF
- 수정한 27차시 활동지
- 웹앱 정책 148개의 이름·원문 위치 색인. 가상 사례와 탐구 질문은 사실 근거에서 제외했습니다.
- 2026-10-15 수집한 인구 자료 저장본: 읍면동 2026-09, 양산시 전체 연령 분포 2026-08 기준
- 원문·색인·예시·학생 제안을 구분하는 자료 읽기 안내

지식 파일은 웹앱과 자동 동기화되지 않습니다. 갱신이 필요하면 `node scripts/prepare-gem-knowledge.mjs`로 다시 준비하고 Gem의 첨부 파일도 교체합니다. 이 명령은 `artifacts/gemini-knowledge/population-snapshot.json`이 있으면 그 공개 API 저장본을 사용하고, 없으면 기준 시점을 명시한 로컬 정적 저장본을 사용합니다.
