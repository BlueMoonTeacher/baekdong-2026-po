# 양산 인구 탐험

학생용 도구: https://baekdong-population-2026.web.app/explore

기존 수업 프로젝트 사이트의 ‘양산 인구 탐험’ 링크로도 접속할 수 있습니다. 로그인 없이 지도·정책·원문을 조회하며, 학생 제안서는 각 브라우저에 저장되고 파일로 내려받거나 인쇄할 수 있습니다.

## 집에서 이어서 작업하기

```powershell
git clone https://github.com/BlueMoonTeacher/baekdong-2026-po.git
cd baekdong-2026-po
npm install
npm run dev
```

브라우저에서 http://127.0.0.1:5173/explore 를 엽니다. 로컬에서는 공개 인구 저장본을 먼저 표시한 뒤 Vite 프록시를 통해 운영 `/api/population`을 호출합니다. 개발 서버와 `npm run preview` 모두 같은 API를 사용합니다. 호출에 실패하면 저장본과 연결 상태를 표시하며, 저장본도 없으면 다시 불러오기 안내를 표시합니다.

화면은 `src/explorer/Explorer.jsx`, 디자인은 `src/explorer/explorer.css`, 가공한 정책 자료는 `src/explorer/policies.json`, 실제 행정경계는 `src/explorer/map.json`에 있습니다. 원문 PDF와 공개 인구 저장본은 `public/explore/`에 있습니다.

## 전자칠판에서 탐험하기

`/explore`의 기본 모드는 저학년입니다. 저학년은 1,000명 단위 사람 그림, 처음과 지금의 인구, 두 동네의 그림 비교를 봅니다. 고학년은 읍면동별 비율과 남녀 구성, 월별 인구 그래프 및 숫자 표, 두 동네의 차이, 양산시 전체 나이 자료를 봅니다. 정책 제안과 근거 담기는 **6학년 수업**을 선택했을 때만 표시됩니다. 기존 제안서 초안은 브라우저에 계속 보관됩니다.

**전체 화면**은 가로형 전자칠판에서 지도와 동네 상세, 월 조절 도구를 한 화면에 배치합니다. 지도에는 확대/축소와 터치 이동·두 손가락 확대, 13개 동네 선택 버튼이 있습니다. 제목은 일반 화면의 앱 헤더에 한 번만, 전체 화면에서는 전용 헤더에 한 번만 표시합니다. 재생/일시정지 버튼 하나와 월 선택을 헤더에 두고 아래에는 월 슬라이더만 둡니다. 검산된 관측 월만 사용하며 빠진 월을 0명으로 만들지 않습니다. 재생은 마지막 달에서 멈춥니다. 전체 화면 종료 또는 Esc로 돌아올 수 있습니다. 브라우저가 Fullscreen API를 허용하지 않아도 넓은 화면 배치는 적용됩니다.

지도와 상세 탐구는 `src/explorer/PopulationMap.jsx`, `src/explorer/PopulationLab.jsx`, `src/explorer/population-lab.css`에 있습니다.

## 더 자세한 인구 API

현재 연결된 [양산시 지역별 인구 API](https://www.data.go.kr/data/15082066/openapi.do)는 행정동 코드와 기간으로 조회하며 읍면동별 인구·남녀 수·전월 증감을 제공합니다. 동네를 선택하면 이 데이터를 상세 화면에 표시합니다. [지역별 인구 동태 API](https://www.data.go.kr/data/15083466/openapi.do)는 출생·사망·자연증가 등을 제공하지만 현재 저장본에는 검증된 동태 응답이 없어 표시하지 않습니다.

**동네 자세히**에서 [SGIS 인구 통계 API](https://sgis.mods.go.kr/developer/html/newOpenApi/api/dataApi/census.html)를 연결합니다. 인구·가구·평균 나이·인구밀도와 집계구별 인구를 조회합니다. 기준연도는 API가 반환하는 목록에서 선택합니다. 저학년은 사람 수와 가구, 고학년은 평균 나이와 밀도까지 설명합니다. 현재 양산시 API의 5자리 코드에 접두사를 붙이지 않고 해당 연도 공식 경계의 이름으로 SGIS 코드를 대응합니다. 비공개·누락 값은 0으로 바꾸지 않습니다.

SGIS 인구주택총조사는 연도별 통계이며 월별 주민등록 인구와 기준이 달라 별도 출처·기준연도로 표시합니다. 2026-10-10 검증에서 최신 인구는 2024년, 집계구 경계 API는 2025년을 반환했습니다. 연도 불일치로 집계구 위치 지도는 연결하지 않고 **2024년 집계구 인구를 선택·표로 조회**합니다. 집계구 번호는 학습용 순서이며 공식 행정동·아파트 이름이 아닙니다. 물금읍 233개 집계구를 실제 조회했습니다. 읍면동별 연령 분포는 아직 연결하지 않았으며 기존 나이 탭은 계속 **양산시 전체**로 표시합니다.

로컬 Vite 서버의 `/api/sgis` 미들웨어는 제외 파일 `.env.local`의 `SGIS_SERVICE_ID`, `SGIS_SECURITY_KEY`를 읽습니다. `VITE_` 접두사를 붙이지 않습니다. 인증·토큰 재발급·캐시는 서버에서 처리하고 브라우저에는 공개 통계만 반환합니다. `node scripts/probe-sgis.cjs`로 공개 응답을 점검할 수 있습니다. Firebase에서는 같은 이름의 Secret Manager 비밀값 두 개를 설정한 뒤 `sgisDetails` 함수와 Hosting 경로를 함께 배포합니다. 2026-10-10 운영 비밀값 등록과 함수·Hosting 배포를 완료했습니다. 인증키는 Git이나 공개 빌드에 포함하지 않습니다.

## 정책 읽기

기본 정책 63개(2025년 17개·2026년 46개)의 학습 내용은 `src/explorer/policy-learning.mjs`에 있습니다. 원문에 근거한 대상·금액·시간·자격·절차, 쉬운 설명, 가상 생활 사례, 정책별 탐구 질문을 구분합니다. `PolicyReading.jsx`에서 저학년은 생활 속 이해 질문, 고학년은 접근성·효과·지표를 비교하는 질문을 표시합니다. 어려운 용어의 뜻을 함께 보여 주고 원문 링크는 설명을 검증하는 보조 자료로 둡니다. 추가 85개는 원문 목록이며 아직 별도의 학습 설명을 가공하지 않았다고 명시합니다. 신청 안내가 아니라 해당 연도의 수업 자료이며 모집 종료·계획/실행 차이·아동수당 원문 충돌을 유지합니다.

## 6학년 정책 전달·개선 제안서

수업 흐름은 기존 정책 이해 → 필요한 이웃에게 전달할 계획 → 이해와 반응 확인 → 정책·안내 개선 제안입니다. 홍보 부족을 확정된 사실로 제시하지 않고 학생이 확인할 질문으로 기록합니다.

정책 찾기에서 자료를 담은 뒤 **우리의 제안** 오른쪽의 **기본정보로 가져오기**를 누르면 기존 정책과 대상, 쉬운 설명이 연결됩니다. 학생의 제안자·모둠명과 전달 계획 등은 정책을 바꿔도 보존합니다. 바탕 설명을 직접 수정했다면 교체 전 확인하며, 기존 초안도 새 작성 항목과 함께 복원합니다. 초안은 해당 브라우저에 저장되므로 공유 기기에서는 다른 모둠의 작성 내용에 주의합니다.

**이미지 미리보기 → PNG 내려받기**로 패들렛에 올릴 이미지를 만듭니다. 원문 정책과 학생의 설명·제안을 구분하고, 가져온 정책·인구 근거·출처는 별도 컨테이너로 표시합니다. 긴 글은 내용과 출처를 생략하지 않고 여러 이미지로 나눕니다. 최신 공식 안내와 선생님 검토 여부도 포함하며, 이후 글을 수정하면 검토 상태를 해제합니다. 패들렛 자동 업로드는 하지 않습니다.

2026-10-10 제안서 후속 검증: 단위 테스트 37개, 빌드, 데스크톱에서 정책 가져오기·교체 확인/취소·학생 글 보존·새로고침 복원·인구 근거 연결·실제 PNG 내려받기를 확인했습니다. 이번 검증에서는 모바일 테스트를 수행하지 않았습니다. 이후 Hosting과 SGIS 함수를 운영 배포하고, 운영 HTML과 로컬 빌드 일치 및 두 인구 API의 HTTP 200 응답을 확인했습니다. SGIS 물금읍 조회는 2024년 인구 115,169명·233개 집계구를 반환했습니다.

## 배포

Node.js 22와 Firebase CLI를 사용합니다. 기존 Firebase 프로젝트 `baekdong-population-2026`에 접근할 수 있는 계정으로 로그인합니다.

```powershell
firebase login
npm run build
firebase deploy --only hosting
```

서버 코드도 바꿨다면:

```powershell
npm install --prefix functions
firebase deploy --only functions:population
```

공공데이터 인증키는 Google Secret Manager의 `YANGSAN_DATA_KEY`에 저장되어 있습니다. 집에서 저장소를 내려받아도 서버의 기존 키와 자동 갱신은 유지됩니다. 인증키를 소스에 넣거나 GitHub에 올리지 마세요. 로컬에서 직접 자료를 갱신하려면 저장소 최상위의 제외 파일 `api-key.txt`에 키를 넣고 `node scripts/sync-population.cjs`를 실행합니다. 키 변경 시 `node scripts/set-population-secret.cjs`는 원본 파일에서 표준입력으로 전달하며 추가 키 파일을 만들지 않습니다.

## 자료와 갱신 방식

- 같은 Firebase 프로젝트의 Firestore `populationSnapshots/current`에 공개 통계 캐시를 저장합니다. 클라이언트에서 캐시 문서를 변경할 수 없습니다.
- Firebase Functions `populationData`가 `/api/population`으로 자료를 제공하고, `refreshPopulation`이 매일 오전 8시(한국 시간) 갱신합니다.
- 함수는 최소 실행 인스턴스 0, 최대 1로 설정했습니다. 컨테이너 이미지 정리는 7일 기준입니다. Functions·Scheduler·Firestore 사용량은 연결된 Blaze 결제 계정에 적용됩니다.
- API 연결이 안 되면 마지막 저장본을 표시합니다. 화면에 자료 수집일과 각 통계의 실제 기준 월을 표시합니다.
- 지도는 통계청 SGIS 경계를 가공한 vuski/admdongkor의 2026-07-01 자료를 양산시만 추출해 사용했습니다. 지도 출처와 이용 조건은 도구의 ‘자료와 출처’ 및 `public/explore/MAP-LICENSE.txt`에 있습니다.

## 원자료에서 발견한 차이

최초 수집(2026-10-09) 기준 읍면동 인구는 2026년 9월까지 제공됩니다. 강서동은 지역별·읍면동별 API 응답이 누락되어, 시 전체 성별 합계에서 다른 12개 지역 합계를 뺀 **계산값**으로 명시합니다. 다른 지역이 추가로 누락되면 완전한 월로 취급하지 않습니다.

2025년 10월과 2026년 4월은 지역별 합계 검산을 통과하지 못해 제외했습니다. 연령별 자료도 검산하여 합계가 맞는 월만 사용하며 최초 화면은 2026년 8월 자료입니다. 숫자를 0으로 대체하거나 선택한 동네의 나이 분포라고 표현하지 않습니다.

2026 가이드북과 로드맵의 아동수당 나이·금액이 달라 두 안내를 나란히 명시했습니다. 2025 자료는 시행계획이며, 사업 완료나 현재 신청 가능 상태를 의미하지 않습니다. 2025 중점 사업 17개와 2026 쉬운 설명 46개를 먼저 표시하고, 2026 원문 전체 목록 131개도 검색할 수 있습니다.

2025 시행계획 원문은 양산시청 공개 페이지 https://www.yangsan.go.kr/portal/contents.do?mid=0401150100 에서 확보했습니다. 제공받은 2026 PDF 두 개도 원문 그대로 다운로드할 수 있습니다.

## 이번 작업 확인 기록

2026-10-10 후속 수정: 빌드·단위 테스트 27개, SGIS 실제 인증과 통계 응답, 헤더·메뉴 정렬, 간소화한 재생·전체 화면, 저학년/고학년 정책 상세, 모바일 줄바꿈을 확인했습니다. SGIS 비밀값이 클라이언트 빌드에 포함되지 않는 테스트도 추가했습니다. 이 후속 변경은 운영 배포하지 않았습니다.

빌드와 단위 테스트 9개가 통과했고, 독립 브라우저에서 지도 선택, 읽기 수준 전환, 정책 필터, 근거 담기, 제안서 내려받기, 새로고침 후 초안 복원, PC·모바일 화면을 확인했습니다. Firebase 서버 캐시 조회와 자동 갱신 작업 1회도 실행했습니다. 이후 사용자의 요청으로 추가 검증은 생략하고 GitHub 업로드 및 배포를 진행했습니다.
