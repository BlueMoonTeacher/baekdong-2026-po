# 수업자료 폴더 안내

현재 사용하는 확정본은 `2026_인구교육_26~30차시_개정본`입니다.

| 폴더 | 내용 |
| --- | --- |
| `2026_인구교육_26~30차시_개정본/차시별 PPT` | 1~30차시 PPT 21개, PDF 변환본, PDF 기반 미리보기 |
| `2026_인구교육_26~30차시_개정본/차시별 활동지` | 기존 서식을 유지한 활동지 22개, 차시별 PDF, 미리보기 |
| `2026_인구교육_26~30차시_개정본` | 확정 지도안, 교사용 안내, Gems 설정문과 학생 시작문 |
| `공통자료` | 공통 수업 계획표 원본 |
| `2차년도 PPT` | 제공받은 원본과 프로젝트 순서 교환 작업본, 로컬 보관 |
| `2차년도 활동지` | 제공받은 통합 원본과 초기 차시별 분리본, 로컬 보관 |
| `보관/원본지도안`, `보관/원본이미지` | 초기 원본 자료 |
| `보관/이전초안` | 초기 프로젝트 교환본, 폐기된 16~30차시 연계 초안 |

변환·검증용 작업 기록은 저장소 루트의 `artifacts`에 있습니다. 앱 소스는 `src`, 정적 미리보기는 `public`, 빌드 도구는 `scripts`, 검증은 `tests`, 서버 함수는 `functions`에 유지합니다. `dist`, `node_modules`, `.firebase`는 생성되는 폴더입니다.

PPT/HWP/HWPX는 Firebase Storage에 게시하며 Git에 추가하지 않습니다. 확정 자료 원본을 로컬에서 다시 받을 때는 `npm run materials:restore`를 사용합니다.

- `수업자료등록목록.json`: 차시별 자료, PDF와 미리보기 연결
- `공통자료등록목록.json`: 공통 계획표와 지도안 연결
- `수업자료Storage목록.json`: 게시된 원본의 경로, 크기, 체크섬

원본을 수정하면 `npm run materials:publish`로 게시하고 `npm run deploy`로 웹앱에 반영합니다. PDF와 미리보기도 원본 수정에 맞춰 갱신해야 합니다. 웹앱·Gems·NotebookLM 연계 범위는 26~30차시입니다.
