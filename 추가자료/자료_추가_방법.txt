이 폴더에 PPT, 활동지, PDF 등의 파일을 넣어 주세요.
다음 빌드와 배포 때 자동으로 웹앱 자료실에 연결됩니다.

권장 파일 이름 (차시는 변경된 전체 30차시 기준):
P1_01차시_세대공감_PPT.pptx
P2_11차시_인터뷰_활동지.hwpx
P3_26차시_양산시정책_PPT.pptx

차시를 쓰면 프로젝트도 자동으로 판단합니다.
P2_굿즈제작_참고자료.pdf처럼 프로젝트만 써도 됩니다.
반영 명령: npm run deploy

배포된 폴더 자료는 주소를 아는 사람이 다운로드할 수 있습니다.
교사용 수업 자료만 넣고 학생 개인정보를 포함하지 마세요.

2차년도 활동지:
통합 원본과 예시 1차시 파일은 원래 위치에 보관합니다.
차시별 활동지 폴더의 등록목록.json에 있는 파일만 자료실에 연결됩니다.
21~22, 23~25, 28~29차시는 한 파일을 해당 차시에 연결하며 수업 자료 셀을 합칩니다.
분리 재실행: lxml이 설치된 Python으로 python scripts/split-worksheets.py
로컬 반영: node scripts/sync-materials.mjs 또는 npm run build
계획서 대조 결과: 2차년도 활동지/차시별 활동지/계획서_대조_결과.md
확정 수업자료는 2026_인구교육_26~30차시_개정본 폴더에 있습니다.
수업자료등록목록.json에 등록된 PPT·PDF·활동지 원본과 미리보기 이미지만 연결됩니다.
PPT 미리보기는 글꼴을 보존한 PDF 변환본에서 만든 페이지 이미지를 사용합니다.
PPT·한글 원본은 Firebase Storage에 보관합니다. 복원: npm run materials:restore
원본 수정·추가 후 먼저 npm run materials:publish를 실행하고 빌드·배포합니다.
